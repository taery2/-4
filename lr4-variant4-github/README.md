## Задание
Размеры: 1 000, 5 000, 10 000, 100 000; распределение А — арифметическая прогрессия; 1 000 успешных запросов на каждый размер. Дополнительное Б4 — поиск первого/последнего вхождения и подсчёт повторов за `O(log n)`.

Используется `A[i]=17+7*i`. Реализованы линейный, двоичный и интерполяционный поиск. Для каждого запроса считается индекс и число сравнений.

## Б4 — границы диапазона
Проверочный массив `[1,2,2,2,4,5,5,7,7,7,7,9]`:
- ключ 2: индексы 1–3, всего 3;
- ключ 5: индексы 5–6, всего 2;
- ключ 7: индексы 7–10, всего 4;
- ключ 3: не найден.
Два двоичных поиска `lower_bound` и `upper_bound` дают границы за `O(log n)`.

## Вывод
На арифметической прогрессии интерполяционный поиск использует линейную зависимость ключа от индекса. Двоичный поиск требует логарифмического числа сравнений; линейный — в среднем порядка `n/2` для успешных равновероятных запросов.
